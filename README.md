### **Maiden Alert**
## ✨ Settings _(`/malert`, `/maidenalert`)_

  - Disable Sound: Disable/Enable sound notification
  - Message Alert: Disable/Enable chat message notification
  - Sound: Choose a sound from the list to be played as the notification sound if enabled
  - Tracker Overlay: Disable/Enable Maiden entity on-screen tracker overlay
  - Tracker Distance: Set the distance where the Maiden tracker temporarily hides when you are close enough
  - Tracker Scale: Adjust the size of the tracker icon, arrow, and text
  - Test Notification: Press to simulate the notification happening _(Following settings)_

## 🧾 Notes

- Every time that you are doing a **Fate** and any type of **Forlorn Maiden** spawns, you will receive a notification according to your `/malert` settings.

Don't miss any Maiden spawn anymore!
